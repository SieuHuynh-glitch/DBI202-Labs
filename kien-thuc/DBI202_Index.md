# 📚 DBI202 - Database Systems

Chào mừng bạn đến với môn học DBI202. Không gian này được thiết kế để kết hợp giữa việc tự học, nghe giảng trên lớp và tương tác với AI, giúp tối ưu hóa quá trình học tập.

## 🗂️ Cấu trúc thư mục

1. **[[1. Class Notes]]**: Nơi lưu trữ ghi chép cho từng chương dựa trên Slide bài giảng. Hãy ghi lại ý chính, code SQL hoặc câu hỏi chưa hiểu tại đây.
2. **[[2. AI Interactions]]**: Chứa các cuộc hội thoại, giải thích chuyên sâu hoặc các đoạn prompt hay khi làm việc với AI để giải bài tập, hiểu concept khó. Việc lưu lại giúp AI có context tốt hơn cho các lần sau.
3. **[[3. Key Concepts]]**: Ghi chú các định nghĩa cốt lõi, công thức, cheatsheet, và các quy tắc (ví dụ: Chuẩn hóa Normalization, ERD).
4. **[[4. Resources]]**: Chứa tài nguyên học tập, link hữu ích, hoặc file bài tập (như assignment).

## 💡 Mẹo sử dụng với AI
Khi gặp bài toán khó (như viết câu truy vấn SQL phức tạp), hãy tạo một file mới trong thư mục **2. AI Interactions**, copy nguyên văn đề bài và những gì bạn đã thử làm. AI sẽ đọc file này và hướng dẫn bạn dựa trên những kiến thức bạn đã ghi chép trong **3. Key Concepts**.
